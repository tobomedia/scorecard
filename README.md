# Scorecard

Mobile web app for keeping score while watching a match. Ships with Rugby Union and Football presets, and you can build your own scoring system. Works offline and can be installed to your home screen.

See [docs/MVP-SPEC.md](docs/MVP-SPEC.md) for the product definition.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy (GitHub Pages)

Every push to `main` runs `.github/workflows/deploy.yml`, which builds and publishes the site.
Repo **Settings → Pages → Source** must be set to **GitHub Actions**.

The build (`scripts/build.mjs`):
- renames `app.js` and `styles.css` to content-hashed names (e.g. `app.3f9a1c2b.js`)
- rewrites `index.html` and `sw.js` to use them
- stamps a version into the service worker cache name and the home screen label

You never bump versions by hand. Installed phones check for updates each time the app opens or comes back to the foreground, then show a "tap to update" bar.

To try a production build locally:

```bash
node scripts/build.mjs && cd _site && python3 -m http.server 8000
```

## Files

- `index.html`, `styles.css`, `app.js`: the app (plain JS, no build step)
- `sw.js`, `manifest.webmanifest`, `icons/`: offline support and install
- `scripts/build.mjs`, `.github/workflows/deploy.yml`: deploy build
- `assets/paint/`: spray-paint SVGs (frames, splats), generated by `python3 scripts/gen-assets.py`. New asset files must be listed in `ASSETS` in `sw.js`; the build fails if one is missing.
- `assets/fonts/`: Roboto Condensed (SIL Open Font License), bundled so it works offline
- All data lives in the phone's `localStorage`

## Debug mode

Tap the version number at the bottom of any screen 5 times to toggle it. A pink **DEBUG** tag shows while it's on.
On the live match screen, a debug panel (scroll below the score buttons) lets you:
- skip the clock forward (+1 / +5 min)
- jump to 10s before the end of the period
- jump to 10 min over (to trigger the reminder)
- reset the period
- test the cue (flash, vibrate, beep)

## Live score sharing (Cloudflare)

`live/` is a small Cloudflare Worker with a Durable Object that relays live scores. The scorer's phone sends the whole match state on every change; viewers on `#/watch/<id>` hold a WebSocket open. Only the phone that started a live match can update it, using a secret key it generated. Matches are deleted 30 days after their last update. It runs on Cloudflare's free plan, which doesn't bill for overage: requests just fail until the daily reset.

### One-time setup

1. Create a free account at dash.cloudflare.com.
2. In the dashboard, open **Workers & Pages** once and pick a `workers.dev` subdomain if asked.
3. Go to **My Profile → API Tokens → Create Token** and use the **Edit Cloudflare Workers** template. Account resources: your account. Zone resources: All zones. Copy the token.
4. Copy your **Account ID**. It's shown on the right of the Workers & Pages overview, or in the URL after `dash.cloudflare.com/`.
5. In GitHub, go to **Settings → Secrets and variables → Actions → New repository secret** and add:
   - `CLOUDFLARE_API_TOKEN`: the token
   - `CLOUDFLARE_ACCOUNT_ID`: the account ID
6. Run the **Deploy to GitHub Pages** workflow (Actions tab), or push anything.

The workflow deploys the Worker, finds its `https://scorecard-live.<subdomain>.workers.dev` address and builds it into the app. Until the secrets exist, the Worker step is skipped and the Go live button is hidden. To use a custom domain instead, set a repository variable `LIVE_API_URL`.
